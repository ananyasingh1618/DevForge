# DevForge frontend

React + TypeScript (Vite), Tailwind CSS v4 with a CSS-variable design-token layer
(`src/index.css`), React Router, ESLint (typescript-eslint), and Vitest + React Testing
Library.

Full setup/architecture docs land in the root [README.md](../README.md) at the end of the
Foundation phase (Milestone 12). For now: `pnpm dev` to run it, `pnpm test` / `pnpm lint` /
`pnpm typecheck` to verify it.
